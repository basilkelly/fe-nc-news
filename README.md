# What is Fe NC News?
Fe NC news is the frontend for the project nc news, built using react. The site uses much of the api to display a News website featuring articles, commenting, user profiles, voting and more. 

# How to Clone and setup your own fe-nc-news
A Node Version of v21.4.0 or later is required to run locally.

To Clone fe-nc-news copy the url from the github page (found in the green code button) and run "git clone" command followed by the url in your terminal. The url should look something like this: "https://github.com/basilkelly/nc-news.git"

Use the command "npm run dev" to run vite and view a local version of the site in your browser.


# Using the Website
<img width="1920" height="904" alt="image" src="https://github.com/user-attachments/assets/0031619a-4097-4958-b97a-4a56c5c464d8" />

At the top of the site a navigation bar contains links to the main areas of the website. On the articles page you can use click on a topic to filter the articles to just that specific topic. You can also sort the articles using the dropdown and switch between an ascending or a descending order for that sorting option. 

When on a single article page you can click the thumb icon to like an article, as well as read comments below the article. 
<img width="1920" height="908" alt="image" src="https://github.com/user-attachments/assets/b155f9a9-deb6-4cd9-9fc6-3f3341f95af9" />

The log in screen allows you to sign in as a user, which gives you access to more features than a guest visitor to the site. This includes posting comments, which you can also delete using the delete button on any comment you have written on the website.
